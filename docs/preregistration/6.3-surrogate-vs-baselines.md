# 6.3 — Surrogate against trivial baselines

- **Frozen on**: not yet (draft).
- **Hypothesis**: a per-room surrogate with openings ranks rooms better than floor area
  alone (B7b: area alone reaches Spearman ρ = +0.572 on 2,346 test rooms).
- **Primary metric**: per-room Spearman ρ against `sun_201803211200_mean` (Swiss
  Dwellings v3.0.0), on sites disjoint from training.
- **Baselines** (mandatory): constant, floor area alone, analytic surrogate.
- **Test**: cluster bootstrap by site (`bench.stats.cluster_bootstrap_proportion`
  generalised to ρ), 95 % intervals; repeated splits compared with
  `bench.stats.nadeau_bengio`.
- **Sample size**: the existing 1,205 / 426 / 369 apartment split by site.
- **Success criterion**: ρ(surrogate) > ρ(area alone) with disjoint 95 % intervals.
- **Failure means**: daylight mode stays "experimental" in the README and the paper
  focuses on legalization (option B).
