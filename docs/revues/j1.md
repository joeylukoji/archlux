# Review of milestone 1: types and JSON round trip

## Criterion as written

`ARCHITECTURE.md` §12: milestone 1 delivers "`types`, `io`: JSON round trip".
`MILESTONE-2.md` §1 makes it a prerequisite: "`types.py` and `io/json_io.py` work,
JSON round trip tested". The audit (AUDIT.md, J1: 8/10) added what was missing:
input validation and a published schema.

## Replayed?

Yes, on revision `4861f4c` and later, with Hypothesis (derandomized):

| Test | What it replays | Examples |
|---|---|--:|
| `tests/proprietes/test_json_io.py::test_aller_retour_en_memoire` | the original criterion, arbitrary plans | 200 |

Command: `pytest tests/proprietes/test_json_io.py tests/proprietes/test_json_schema.py`.

## Result

- Round trip exact on every example, certificate included. A performance bound keeps
  its `regime` through a file; a file without `regime` is refused by the reader and by
  the schema (batch 1.6: an unknown guarantee is never upgraded to `"exchangeable"`).
- **Published schema**: `archlux/io/plan-v1.schema.json` (JSON Schema draft 2020-12),
  shipped in the wheel and documented in [the JSON schema page](../reference/schema-json.md).
  JSON Schema cannot say "finite number": only the reader refuses `NaN` and `Infinity`.
- **"Load-bearing incidences" (PLAN.md)**: nothing new to serialize. Batch 1.1 chose to
  read the side of each wall from the proposed plan (ADR-7 rewritten), not to store it.
- **Finding**: the file carries the plan and its certificate, **not the context** it was
  certified against (`Referentiel.aires_min`, `largeur_min`, `Structure`,
  `Orientation`). A third party can read "valid: yes" but cannot re-run
  `verify_exactly` on the file alone: the minimum areas it was checked against are not
  in it. The outline and the load-bearing walls repeated in `murs` are.
- The Frank-Wolfe trace is not serialized (documented in `types.Plan`).

## Decision

**Criterion kept**, extended: the round trip is tested on real outputs, and the schema
is published and tested against the writer and the reader. The finding goes to batch
E5 (phase 3, schema v2 with English keys): **v2 serializes the `Contexte` next to the
certificate**, so that a certificate can be re-checked from its file. Traced in
[ADR 0002](../adr/0002-milestone-criteria-rewritten.md).
