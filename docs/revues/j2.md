# Review of milestone 2: classic legalization

## Criterion as written

`MILESTONE-2.md` §0, the single acceptance criterion:

```python
@given(plan=plans_quelconques(), ctx=contextes())
@settings(max_examples=500, deadline=None)
def test_toute_sortie_est_valide(plan, ctx):  # lang-ok: quoted as written
    assert archlux.legalize(plan, ctx).certificat.geometrie.valide
```

"Measure for the paper: rate of valid plans before / after correction, on the outputs
of 3 public models." Header of the file: "**This milestone is enough for a first
publishable paper.**"

## Replayed?

Yes, on revision `9632917` and later.

1. **The test that closed the milestone was not the one written.**
   `tests/proprietes/test_acceptation_jalon2.py` draws `plans_valides()`, guillotine
   tilings that are *already valid*, under one fixed context. An identity function
   would pass it. The criterion as written draws arbitrary plans and contexts; it is
   now `tests/proprietes/test_milestone2_as_written.py` (500 examples).
2. **With load-bearing walls** (PLAN.md): the same file draws a valid plan with a
   load-bearing wall and minimum areas, applies one fault (`data.corruption`,
   0.1 to 0.5 m), with and without `pavage`: 60 examples in CI, **2000** replayed.
3. **Measurement** (replaces `j2_brut.csv`, 2 hand-made plans):
   `python experiences/j2_validity.py` writes `resultats/j2_validity_raw.csv`, byte
   for byte reproducible (seed 17).

## Result

**Arbitrary plans and contexts, as written (500 examples, derandomized):**

| Outcome | n |
|---|--:|
| plan returned, certified valid, confirmed by the independent checker | 129 |
| refused, `InvariantViole` "gap: uncovered area" (no `pavage`) | 363 |
| refused, `Infaisable` | 8 |
| **certificate that lies** | **0** |
| crash (untyped exception) | 0 |

The literal test (`legalize(...).certificat...`) therefore **fails** on 371 of 500
inputs, all of them refusals: no returned plan is invalid. Most refusals are a gap that
`legalize` without `pavage` cannot fill, raised as `InvariantViole`, whose docstring
says "most often an internal bug". Here it is an input limit.

**90 synthetic tilings, load-bearing wall on the cut, minimum areas at 80 %, one fault
per plan** (`resultats/j2_validity_raw.csv`; valid before: 0 of 540):

| Fault amplitude | `pavage=False`: valid after | `pavage=True`: valid after | Median max displacement |
|--:|--:|--:|--:|
| 0.10 m | 35 / 90 (the rest: gap refused) | 90 / 90 | 0.10 m |
| 0.25 m | 44 / 90 | 90 / 90 | 0.25 m |
| 0.50 m | 44 / 90 | 90 / 90 | 0.50 m |
| all | **123 / 270** | **270 / 270** | |

The guarantee benchmark (`benchmarks/guarantees`, 200 scenarios per mode, walls
included) agrees: 0 false certificate in every mode.

**The paper baseline was never built.** `j2_brut.csv` holds two hand-made plans, not
"the outputs of 3 public models". Only one public generator has been measured since
(HouseDiffusion, milestone 8, about 20 %).

## Decision

- **Criterion kept, read as**: every plan `legalize` returns is valid (exact proof and
  independent checker), and every refusal is a typed `ArchluxError`. Tested as written
  (arbitrary plans and contexts) and with walls, areas and one fault.
- **The gap refusal is mistyped**: an input limit raised as an "internal bug". Phase 3.4
  gives it its own type (an `UnsupportedInput` naming `pavage=True` as the fix).
- **"This milestone is enough for a first publishable paper": withdrawn.** It rested on
  a baseline of 3 public generators that does not exist. The validity rate on real
  generators is milestone 8 (one generator) and phase 6.5 (a second one).
- Traced in [ADR 0002](../adr/0002-milestone-criteria-rewritten.md).
