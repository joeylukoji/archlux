# Milestone reviews (PLAN.md phase 2)

Phase 1 fixed what the library claimed. Phase 2 asks whether the milestones that were
declared done **were done correctly**, now that the code is fixed. Each milestone gets
one report with the same four steps:

1. **Criterion as written**: quoted from its `MILESTONE-N.md` (or `ARCHITECTURE.md`
   §12 for milestone 1), never paraphrased.
2. **Replayed?**: which test or experiment was run again, with which command, seed and
   revision; or why it could not be, and what it waits for.
3. **Result**: the figures, next to the ones published before.
4. **Decision**: criterion kept, rewritten (traced in
   [ADR 0002](../adr/0002-milestone-criteria-rewritten.md)), or suspended.

A figure of `resultats/` is regenerated by `make resultats` (synthetic experiments) or
`make resultats-corpus MSD=... SD=... HD=...` (corpora that cannot be redistributed,
see [data](../donnees/index.md)).
