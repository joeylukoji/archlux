# Review of milestone 7: real MSD plans

## Criterion as written

Milestone 7 has no `MILESTONE-7.md`; its claims are in `resultats/j7_reparation.md`
and the README: **93.9 %** of 4 796 corrupted MSD plans repaired
(Wilson 95 % [93.2, 94.5]), idempotence on 400 real plans (400 / 400 valid after
`legalize`), and a per-room study of Swiss Dwellings labels. PLAN.md asks: do the
load-bearing walls of batch 1.1 change the 93.9 %? What are the 68 % of MSD apartments
the loader rejects?

## Replayed?

**Not on the corpus: awaiting a local run.** MSD (Kaggle, CC BY-SA 4.0) is not
redistributed and not reachable from the CI. What was done here:

1. **The published table is now reproducible from its raw rows.** No script produced
   `resultats/j7_reparation.md`. `experiences/j7_msd_summary.py` (44 lines) rebuilds
   it from `resultats/j7_reparation_brut.csv` and matches **every cell** of the
   published table (9 rows, rates and Wilson intervals).
2. **Finding: the "fallback" column is not the rule the text describes.** The text says
   "try `pavage=True`, fall back on plain `legalize` if the grid is not recoverable".
   That rule gives **93.5 %** [92.8, 94.2]. The published **93.9 %** falls back on
   **any** refusal of `pavage=True` (grid, infeasibility or proof). Both are strategies
   a user can apply, since every output is certified; the published number goes with
   the second, now stated in the script.
3. **The corpus scripts are rewritten** (English, public API, data path required, no
   `D:/` default, no timing column): `j7_msd_repair.py` (48 lines, same derived seeds as
   the published run, so the same faults), `j7_msd_idempotence.py` (44 lines). They run
   in CI on a fabricated MSD-format mini-corpus (`tests/test_experiments.py`).
4. The Swiss Dwellings scripts (`j7_sd_etiquettes.py`, `j7_sd_par_piece.py`, 130 lines
   each) are unchanged: they need a supervised-set builder in the library (AUDIT.md
   M12) that cannot be checked without the data.

**Command for the local run** (from the repository root):

```
make resultats-corpus MSD=/path/to/mds_V2_5.372k.csv
```

## Result

- Published figures, reproduced from their raw rows: all faults 93.9 % with fallback on
  any refusal (93.5 % with fallback on an unrecoverable grid only), 93.0 % with
  `pavage=True` alone, 35.9 % without it.
- **Walls (PLAN.md question)**: MSD separators carry no load-bearing annotation
  (`docs/donnees/msd.md`), so `Structure.murs_porteurs` is empty on this corpus and
  batch 1.1 cannot change the result through walls. Other phase 1 changes can: the
  tiling grid now anchors on the outline and reads the order from the snapped plan
  (fixes after 1.5), and the proof is exact. **The 93.9 % was measured before them.**
- **Rejected apartments** (`resultats/j7_msd_idempotence.md`, 1 247 read, 400 kept):
  426 degenerate rooms after gluing, 240 non-simple outlines, 143 oblique rooms, 19
  degenerate after snapping, 11 too many sub-rectangles, 5 degenerate gluing, 2 too
  many rooms. Which of these are loader limits and which are real MSD geometry needs
  the corpus.

## Decision

- **Figures kept, marked "measured before phase 1"** until the local run replaces them;
  every document that quotes 93.9 % states the fallback rule it uses.
- **Local run owed before the phase 2 exit gate**: `make resultats-corpus`, then
  replace `j7_reparation_brut.csv` and `j7_reparation.md` by `j7_repair_raw.csv` and
  `j7_repair.md`, and update the figures of the README, `api.legalize` and this report.
- The rejection analysis and the Swiss Dwellings refactor (M12) go with that run.
