# Review of milestone 8: really generated plans

## Criterion as written

Milestone 8 has no `MILESTONE-8.md`; its claims are in `resultats/j8_generation.md`:
740 plans generated by HouseDiffusion (1 000 steps, three conditioning sets), of which
`legalize(..., pavage=True)` repairs **about 20 %** (20.3 %, 17.8 % and 23.0 % at
`largeur_min = 0.50 m` and a repair budget of 16), moving rooms by about 40 % of their
side. PLAN.md asks to replay it with the new Frank-Wolfe and the load-bearing walls,
and to add resemblance metrics (phase 6.5).

## Replayed?

**Not on the generated plans: awaiting a local run.** The plans come from HouseDiffusion
(GPL v3, not imported by archlux) through a JSONL file produced outside the repository
(`vendor/j8_generer.py`); neither the file nor the model is reachable from the CI.

- The headline rates **are recomputed from the versioned raw rows**
  (`resultats/j8_*_brut.csv`): 20.3 % (star), 17.8 % (plausible), 23.0 % (diverse),
  budget 16, `largeur_min = 0.50 m`, as published.
- The scripts (`j8_generation.py`, 443 lines; `j8_visuels.py`, 169 lines) are **not**
  refactored: the missing library functions (AUDIT.md M12: a loader "generated boxes →
  `Plan` + `Contexte`", a generic Wilson summary) cannot be checked against their
  current output without the JSONL. That refactor goes with the local run.

**Command for the local run**:

```
make resultats-corpus HD=/path/to/j8_plans.jsonl
```

## Result

- The published rates stand as measured **before phase 1**. Phase 1 changed what they
  depend on: tiling grid anchored on the outline and order read from the snapped plan
  (the benchmark mode "noisy tiling" went from 1 to 118 repaired plans out of 200),
  exact proof, typed refusals. The rate may rise; it has to be measured.
- Load-bearing walls: HouseDiffusion outputs carry none, so batch 1.1 does not apply
  unless a structure is imposed; the replay should add one scenario with a
  load-bearing wall on a generated partition.
- Resemblance metrics (how far the repaired plan is from the generated one, beyond the
  maximum displacement): phase 6.5.

## Decision

- **Figures kept, marked "measured before phase 1"**, with the command that replaces
  them. **Local run owed before the phase 2 exit gate.**
- The claim stays what the milestone found: the method repairs about one generated
  plan in five, moving rooms a lot. It is not ready for this use case yet.
